# 13 § Tillsyn på plats av arealbaserade ersättningar
Kapitel: 4 kap. Tillsyn på plats av arealbaserade ersättningar

Vid tillsyn på plats av arealbaserade ersättningar kontrolleras alla de skiften för vilka den åtgärd eller de ersättningar som är föremål för kontrollen har sökts. Vid tillsynen kontrolleras den växt som anmälts för jordbruksskiftet samt avgränsningen av basskiftet och jordbruksskiftet.

Vid tillsynen på plats av arealbaserade ersättningar kontrolleras beträffande den ersättning som ska kontrolleras att de villkor för erhållande av ersättning och krav på miniminivå som kan kontrolleras vid tidpunkten för tillsynen iakttas. Om ett villkor för erhållande av ersättning eller ett krav på miniminivå inte kan kontrolleras vid tidpunkten då tillsynen utförs, kan de verifieras vid ett nytt besök eller med hjälp av ett geotaggat fotografi som sökanden lämnar in. Sökanden ska efter tillsynen lämna in ett geotaggat fotografi på begäran av landskapsregeringen. Vid tillsynen på plats är det möjligt att i ändamålsenlig omfattning kontrollera handlingar som hänför sig till villkoren för erhållande av ersättning och kraven på miniminivå.

Vid tillsyn på plats kan utöver flygfotografi- och kartmaterial som ingår i livsmedelsförvaltningens informationsresurs även annat kartmaterial samt flygfotografi- och satellitmaterial utnyttjas.

De iakttagelser som har gjorts vid tillsynen på plats ska riktas till alla de arealbaserade ersättningar i fråga om vilka iakttagelserna påverkar den ersättning som beviljas, även om endast en del av de arealbaserade ersättningarna som gårdsbruksenheten ansökt om kontrolleras vid tillsynen.

Om iakttagelserna vid tillsynen på plats avviker från resultatet av arealövervakningen, används vid beräkningen av ersättningen de iakttagelser som gjorts vid tillsynen på plats.

Efter att sökanden har underrättats om tillsyn på plats eller, om tillsynen på plats genomförs utan förhandsanmälan kan sökanden efter det att tillsynen har inletts inte längre elektroniskt via nättjänsten eller med en applikation som myndigheten anvisar göra sådana ändringar eller tillbakadraganden av ansökan som avses i artikel 7 i förordningen om ansökningssystem. De ändringar och tillbakadraganden som avses i artikel 7 i förordningen om ansökningssystem ska då anmälas skriftligen till Ålands landskapsregering.
