# 3 §

Lån som beviljas enligt denna lag kan vara kortfristigt eller långfristigt. Lån enbart för att förbättra gårdsområde kan dock inte vara långfristigt.

Kortfristigt lån som beviljats för förbättring av byggnad omfattande minst två bostäder kan, för återbetalning av en på enskild bostad beräknad andel, ombildas till långfristigt lån.
