# 14 § Förvaringsutrymmenas säkerhet
Kapitel: 3 kap. Förvaringsutrymmen och utrustning

Utrymmen där hästar hålls ska vara säkra för hästen.

Inredning som hästar kan nå, inklusive väggar och boxdörrar, ska vara utformade på ett sådant sätt att hästar inte kan skadas och vid behov försedda med skydd. Inredning som hästar kan nå ska dessutom vara utformad på ett sådant sätt att skaderisken inte ökar om den utsätts för hästsparkar.

Elledningar och elapparater samt andra anordningar som kan skada hästarna ska vid behov skyddas och placeras på ett sådant sätt att de är utom räckhåll för hästarna.

Avstånd mellan vägg och tak respektive vägg och golv ska vara sådant att hästar inte kan fastna.
