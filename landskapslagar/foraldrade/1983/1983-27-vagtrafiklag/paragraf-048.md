# 48 § Förbud mot oriktig användning av ljus
Kapitel: 3 kap. Regler för trafik med fordon

Fordons ljus får inte användas så att förare av annat fordon kan bländas.

På ett fordon får inte visas annat än vitt eller gult ljus framåt och inte visas vitt ljus bakåt annat än vid backning eller vid arbete som kräver vitt ljus. På fordon som används i polisens tjänsteuppdrag får dock, för stoppande av ett framförvarande fordon, samtidigt med blått blinkande ljus användas ljusanordning som framåt kastar rött blinkande sken.
