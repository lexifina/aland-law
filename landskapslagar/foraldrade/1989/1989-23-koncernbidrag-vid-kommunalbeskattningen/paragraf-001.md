# 1 §

I denna lag finns bestämmelser om hur koncernbidrag skall behandlas vid kommunalbeskattningen.

Med koncernbidrag avses annat bidrag än kapitalplacering som ett rörelsedrivande aktiebolag eller andelslag erlägger till ett annat aktiebolag eller andelslag för dess rörelse, om bidraget inte får avdras enligt landskapslagen (1993:42) om kommunalskatt för näringsverksamhet.
